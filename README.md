# MAD Barbershop

**Responsive multi-page business website built with HTML, CSS and JavaScript.**

A frontend website for MAD Barbershop in Chișinău, focused on presenting
services, business information and driving visitors to online booking.

## Frontend Highlights

The project includes:

- responsive multi-page layout
- semantic HTML structure
- custom responsive navigation
- mobile burger menu
- interactive booking elements
- scroll-based UI behaviour
- video playback controlled with IntersectionObserver
- services and business information pages
- embedded customer reviews
- Google Maps integration
- social media and contact links
- online booking integration

**Frontend stack:** HTML5 · CSS3 · JavaScript

## Pages

`Home` · `Services` · `About` · `Contacts`

## Key Interactions

The JavaScript implementation includes:

- responsive burger navigation
- scroll locking for mobile navigation
- interactive contact UI
- fixed booking button triggered by scroll position
- viewport-aware video playback using IntersectionObserver
